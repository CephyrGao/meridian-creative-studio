# 经纬创意 · 出海营销工作台

公开测试版 0.8.0-beta.1

## 打开工作台

Windows 上将整个压缩包解压到同一文件夹，双击 **Start-Workbench.cmd**。浏览器会打开工作台，终端会显示本机地址。运行期间保持终端窗口打开。需要 Node.js 22 或更高版本。macOS / Linux 可在解压目录运行 `node local.mjs` 后打开终端显示的地址。

直接打开 **preview.html** 可离线查看案例、编辑 Brief、导入 CSV、分析表现和导出已经人工审核的示例创意。实时生成和语义复核请通过启动器打开。

## 首次体验

1. 默认任务为 Folda 随行杯，含美国、印度尼西亚和 TikTok、Meta 的 12 条示例创意。示例评价、引用记录与投放数据均为教学模拟数据。
2. 在「创意工坊」切换市场和平台，打开「脚本与分镜」。每个方向有 4 个镜头，覆盖 0–3、3–7、7–12、12–15 秒。旁白、字幕、广告正文与 CTA 使用目标语言。
3. 到「质检与审核」打开一条创意，检查风险、修改建议和完整内容。填入审阅人、勾选确认后即可导出 Markdown 制作单。修改创意后需要重新运行模型复核和人工审核。
4. 打开「投放复盘」。模拟案例中「早班咖啡 · ID TikTok」的 CTR 为 3.50%，可比素材为 1.92%。CVR 为 1.81%，可比素材为 6.04%。选择「创建下一轮 Brief」会带入原始产品事实、目标市场、实验 A/B、主要指标与观察指标。
5. 「新建营销任务」可从头开始。项目保存在当前浏览器和当前网址下。可在「切换项目」返回既有任务或上一轮。

## 设置与项目资料

左下角「设置」集中管理模型和搜索 API、本地工作目录、双向 MCP 和本地技能。「运行与备份」可查看 Token 用量、错误日志、请求与响应正文，或导出项目备份。从业务页面打开设置后，右上角可返回原页面。

在「设置 → 本地工作目录」选择「新建工作区」，填写名称和工作约定。一个工作区可放多个项目。已有项目可连同关联轮次一起移动，项目记忆和定时任务随项目移动，工作区公共资料留在原处。

以下操作位于左侧「项目资料」。

| 入口 | 可以做什么 |
| --- | --- |
| 文件资料 | 上传一份或多份文件、按文件名与正文查找、查看原文位置、下载原件。阅读时可把一段原文加入当前 Brief，或把整份文件选作 Agent 任务资料。 |
| 本地记忆 | 写入工作区共用的品牌口径、受众偏好或结论。Agent 按任务词检索，置顶笔记优先。项目专属的约定填在「当前项目记忆」。 |
| 联网检索 | 使用「设置 → API 接入 → 搜索 API」选定的服务搜索。可选免密钥的维基百科或自带密钥的 Tavily、Brave Search。FetchURL 读取指定公开网址的正文。搜索摘要和网页都保留来源链接，可存入资料库。 |
| 定时任务 | 选择项目、任务目标、技能和首次时间，可设一次、每天、每周或按分钟重复。可附搜索词、网址、所选文档和单次 Token 预算。列表显示下次执行时间，点「查看结果」可回到对应任务记录。 |

**导入文件。** 资料库支持 Word（DOCX、常见 Word 97–2003 DOC）、Excel（XLSX、常见 Excel 97–2003 XLS）、含文字层 PDF、CSV、TSV、TXT、Markdown 和 JSON。Word 可读正文，新版还可读表格。Excel 按工作表和单元格定位，公式优先展示文件已保存的值。PDF 按页定位。扫描图片需先做 OCR，加密文档需先解锁。单份上限 32 MB，大文件最多索引 40 万字，PDF 最多读取前 600 页，界面会标出截取。原件保存在本机资料库。

打开「设置 → 本地工作目录」，点「选择本地目录」可批量导入，随后点「刷新目录」读取新增和修改的文档。浏览器只能选择文件夹快照时，刷新会再次打开选择器。上传或刷新均不会改写来源文件。在「Agent 工作台 → 资料与联网」勾选文件或填写联网输入，执行记录会保留命中段落及出处。模型使用选中的资料或按当前任务检索到的摘录，并结合 Brief 和本地记忆。

**定时运行。** 在桌面版「设置 → 运行与备份」可以勾选「允许 Windows 在工作台退出后按时启动」。此选项属于当前 Windows 用户，需要保持登录，并将 EXE 放在固定路径。便携版请保持启动窗口与工作台页面打开。离线错过多次会在下次启动时补跑一次。依赖会话密钥的任务在重启后可能提示补充凭据，可填好后继续运行。搜索服务密钥只用于当前工作区的当前会话。

**网页读取。** 桌面版和启动器可直接访问公开 HTTP、HTTPS 的 HTML、纯文本和 JSON 网页。需要登录或依赖浏览器脚本渲染的页面可能没有可提取的正文。单独打开预览 HTML 可以读本地文件和允许浏览器跨域的维基百科搜索。

## Agent 工作台

项目总览和「切换项目」会显示各项目的最后更新时间。项目列表按最近修改排序。保存 Brief、创意、审核、数据、项目记忆或 Agent 任务进度会更新时间。浏览页面和测试连接保留原时间。

在左侧「Agent 工作台」输入任务目标。比如「找出点击高但转化差的素材，再设计下一轮 A/B 实验」，工作台会用当前项目的投放数据执行复盘，把发现传给实验设计技能。点击「创建下一轮 Brief」即可使用该实验方案。

内置 13 项技能，包括 Brief 诊断、素材与竞品研究、市场与渠道适配、15 秒广告脚本、创意质检、投放复盘、A/B 实验设计、读取文件、联网搜索、FetchURL、本地记忆检索、发现技能与创建技能。本地模式可完成规则检查与数据分析。连接模型后可根据目标规划任务、生成新脚本、开展语义复核并执行自定义技能。样例脚本和模拟投放数据在结果中标注来源。

「设置 → 本地技能 → 发现技能」可按用途检索已安装技能，或安装内置目录的品牌语气审校、竞品证据表、市场周报和表格洞察。桌面版和本地运行包还可加载 Anthropic 的公开目录或读取一个公开的 `SKILL.md` 原文链接，预览后保存。选择 Agent 的 `skill-creator`，描述要重复的任务，即可起草技能，再编辑和保存。连接模型时会根据目标生成执行说明，离线时提供可编辑的起始模板。保存的自定义技能可重新编辑和导出为 `SKILL.md`。文件顶部用两行 `---` 包住 `name` 和 `description`，下方用 Markdown 写执行说明。`name` 使用小写字母、数字和连字符。导入后可以编辑、启用或停用。这种单文件技能执行文字工作流程，依赖本机脚本或附属文件的技能包暂不支持。

项目记忆用于保存品牌约定。任务记录按项目保存各步骤的状态、结果和来源，停止后可继续未完成的步骤。「执行范围与 MCP 资料」可以选择已连接且声明只读的工具并填写参数。本次工具结果供后续技能引用，连接令牌与工具参数不写入任务记录。

## MCP 连接

打开「设置 → MCP 连接」，在「调用外部工具」选择服务提供的传输方式。

| 传输方式 | 需要填写 | 工作台如何连接 |
| --- | --- | --- |
| Streamable HTTP | MCP 地址，例如 `https://example.com/mcp`，按需填写 Bearer Token | 向同一地址发送请求，支持 JSON 和按请求返回的事件流。 |
| SSE（旧版） | SSE 入口地址，例如 `https://example.com/sse`，按需填写 Bearer Token | 保持事件流打开，从 `endpoint` 事件取得消息地址，持续在原来的事件流接收回复。 |
| stdio（本地进程） | 启动命令、JSON 字符串参数数组，以及服务需要的环境变量 | 在本机启动程序，通过标准输入输出交换消息。支持 `node`、`npx`、`uvx` 或可执行文件完整路径，工具要求的运行时需已安装。 |

例如已有本地服务文件 `C:\MCP Tools\server.mjs`，命令填 `node`，启动参数填 `["C:\\MCP Tools\\server.mjs"]`。服务要求的变量填在「环境变量」中。也可在「从客户端 JSON 填入」粘贴一个服务的配置后检查字段，点击连接时才会发出请求或启动程序。

桌面版和本地运行包支持三种方式。便携版请用启动器打开，或打开终端显示的完整链接。单独打开 HTML 时可连接允许浏览器跨域访问的 HTTP 或 SSE 服务。连接成功后可查看工具清单、参数和结果，将结果加入 Brief，或在 Agent 任务里选用声明只读的工具。断开 stdio 连接会结束本次启动的进程。

在「供其他 AI 调用」确认项目并开启共享，然后选择传输方式。HTTP 客户端使用 `/mcp` 地址，旧版 SSE 客户端使用 `/sse` 地址，二者都使用工作台显示的 Bearer Token。stdio 客户端点击「复制客户端 JSON 配置」即可获得本机启动命令、参数与连接环境变量。连接信息随实际文件位置与本次工作台实例生成。各方式都可调用 `get_brief`、`list_approved_creatives` 和 `get_campaign_report`。编辑项目后可更新快照，停止共享会撤销该项目令牌并关闭 SSE 事件流。重新共享或更换工作台位置后请复制新配置。

## 模型连接

通过启动器打开工作台，打开左下角「设置 → API 接入」，在「模型 API」下配置。选择服务、确认模型 ID、填写该服务的 API Key，点「测试连接」。测试只发送一条固定的短消息，成功后显示服务实际返回的模型和耗时。点击「保存模型连接」后，创意生成和语义复核会共用此配置。刷新页面后需重新输入会话密钥。

| 服务 | 预填 Base URL | 预填模型 ID |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com` | `deepseek-flash` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4.1-mini` |
| 自定义 OpenAI 兼容服务 | 填服务商的 API 基地址，可含 `/v1` | 填网关提供的模型 ID |

自定义地址支持 API 基地址和完整的 `/chat/completions` 地址，例如本机服务 `http://127.0.0.1:1234/v1`。免鉴权的兼容服务可留空密钥。更换服务商或自定义地址后，按新服务的要求填写密钥。

也可在启动器的环境变量中设置 `DEEPSEEK_API_KEY`、`DEEPSEEK_MODEL` 或 `OPENAI_API_KEY`、`OPENAI_MODEL`。自定义服务对应 `COMPAT_BASE_URL`、`COMPAT_MODEL` 和可选的 `COMPAT_API_KEY`。本机 Ollama 会自动检测已安装模型，`OLLAMA_MODEL` 可指定模型名。

自定义任务先保存 Brief，在「创意工坊」生成素材，再到「质检与审核」运行独立模型复核。「测试连接」只验证模型能否返回有效 JSON。每条创意仍需完成事实检查和人工审核。

## 用 Postman、PowerShell 或 OpenAI SDK 测试

本地工作台默认地址为 `http://127.0.0.1:8764`，端口被占用时以启动窗口显示的地址为准。

| 方法与路径 | 用途 |
| --- | --- |
| `GET /api/status` | 查看服务及可用的服务端预设 |
| `POST /api/model/test` | 发送固定探测消息，验证模型回复与 JSON 格式 |
| `POST /v1/chat/completions` | 标准 OpenAI Chat Completions 非流式测试接口，返回 `choices[0].message.content` |
| `POST /api/generate`、`POST /api/audit` | 工作台实际使用的创意生成、独立语义复核接口 |

在已设置 `DEEPSEEK_API_KEY` 的 PowerShell 中，可直接运行以下示例。接口会把消息发送至 DeepSeek。

```powershell
$headers = @{
  Authorization = 'Bearer ' + $env:DEEPSEEK_API_KEY
  'X-Model-Provider' = 'deepseek'
}
$body = @{
  model = 'deepseek-flash'
  messages = @(@{ role = 'user'; content = 'Reply with OK.' })
  stream = $false
} | ConvertTo-Json -Depth 5
$reply = Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:8764/v1/chat/completions' -Headers $headers -ContentType 'application/json' -Body $body
$reply.choices[0].message.content
```

在 Postman 使用相同的 URL、Bearer Token 和 JSON 请求体。OpenAI SDK 的 `base_url` 填 `http://127.0.0.1:8764/v1`。`deepseek` 开头的模型名默认发往 DeepSeek，其他名称默认发往 OpenAI。可使用请求头 `X-Model-Provider: compatible` 和 `X-Model-Base-URL` 明确选择自定义网关。在页面填入的会话密钥仅供页面调用，SDK 或 Postman 可自行传入 Bearer Token，也可使用启动器环境变量。

工作台探测接口接受 `{"provider":"deepseek","model":"deepseek-flash"}`，请求头 `X-Session-Model-Key` 可传会话密钥，留空则使用对应服务的环境变量。成功结果含 `ok`、`reply`、`model`、`elapsed_ms`；上游提供用量时另含 `total_tokens`。服务商返回 401、402、429 时分别显示凭据、余额、限流或额度提示。

供应商接口说明见 [DeepSeek API](https://api-docs.deepseek.com/) 和 [OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。

## 单任务 Token 预算

在「Agent 工作台」的「任务 Token 预算」填写正整数，留空时不限。营销评测也可以为一次模型评测设总预算。预算包括模型规划、生成、复核及兼容接口的每次实际重试。本地技能与 MCP 查询不消耗模型 Token。

请求发出前，工作台根据请求的 UTF-8 字节数、消息开销和该步骤的输出上限保守预留，附图也计入预留。收到服务商的实际 Token 总量后回填，并释放差额。缺少用量回执时保留该次预留。发送期间关闭窗口导致整个请求结果未知时，未确认的在途额度会继续保留。预算用于控制后续请求，服务商账单以服务商计量为准。

若剩余额度不足，任务会暂停并显示所需预留。点「调整预算」，再点「继续未完成步骤」或「继续剩余案例」。已完成的步骤会保留。给原先不限额的任务启用预算时，从启用时开始计算。

## 项目备份与恢复

在「设置 → 运行与备份」点「备份与恢复」。导出的 JSON 包含当前项目所有关联轮次的 Brief 与草稿、文字和图片素材、投放数据、创意和审核记录、Agent 任务及其用到的自定义技能、项目记忆、预算、评测集与人工评分，以及本机已有的运行记录和累计用量。正文记录开启时，备份会包含已记录的脱敏请求内容。

在另一台设备打开工作台，选择备份文件，核对轮次和内容数量后点「恢复为新项目」。每个轮次及任务都有独立的新标识，项目之间的关联会重建。同名而内容不同的自定义技能会以新标识导入。恢复后可继续未完成的步骤。工作区公共文件、工作区记忆与定时规则在项目备份之外。在另一台设备继续文件任务时，可重新导入原文并勾选资料。使用模型或外部 MCP 工具时，在新设备配置相应连接。

## 营销质量评测

左侧「营销评测」预置通勤随行杯、会议便签、夹扣阅读灯三份模拟 Brief，覆盖场景、痛点和社会证明。可把当前项目已保存的 Brief 和参考素材加入新版本，指定市场、渠道、方向及审阅要点。旧版本保留原始输入。

选定一个评测集版本，连接模型 A，点「运行当前模型」。换到模型 B 后，在同一版本再运行一组。每个模型为每个案例生成一条广告。可在 A、B 选择器中挑选实际运行记录，打开各自的调用明细。中断后可连接同一服务地址与模型继续剩余案例。

每组生成后，工作台会自动对照数字和单位、来源、需要佐证的宣称、品牌必用词与禁用词，并给出两类规则通过率。打开「逐案审阅」可核对命中的原文、文案及分镜。审阅人逐项核对事实，按 1–5 分评品牌语气，并选择通过或返修。事实准确率是已审案例中所有宣称均得到 Brief 支持的比例，品牌语气取已审案例平均分，人工通过率取已审案例的最终通过比例。对照表同时显示生成和审阅数量。尚无人工评分时显示「待审」。

## 运行记录与用量

在「设置 → 运行与备份」查看当前项目的输入、输出和已知合计 Token。Agent 任务右侧的「调用明细」显示这一个任务的累计用量，以及它的规划、技能和工具请求。连接测试、创意生成、语义复核及模型的兼容性重试分别计数。本地规则计算无需模型。服务商只返回部分统计时，对应字段标记为「未返回」，汇总显示有回执的次数。升级前的调用没有历史回执。

点「错误日志」可查看失败的模型调用、工具错误和待补充资料的步骤。点每条「详情」能看到发生时间、耗时、关联任务、HTTP 状态、发出的请求体和收到的响应体。模型回复格式不合要求时，记录会同时显示服务商 HTTP 状态和工作台状态。MCP 包含工作台发起的请求，以及外部客户端对本机已授权项目的请求。独立调用本机聊天 API 的外部程序没有项目归属。

正文默认记录在本机。可按项目关闭「记录正文」，之后继续统计用量和状态。日志会遮盖凭据字段和已知密钥，省略图片数据，过长的正文显示截取标记。每个项目保留最近 120 条详情，累计用量单独保存。「导出当前记录」下载筛选后的脱敏 JSON，文件包括当前项目的累计用量。

## 文件格式

Brief 支持 JSON、TXT、Markdown。文本可按「产品介绍：」「核心卖点：」「品牌语气：」「目标市场：」等标签分段。JSON 字段格式可从「下载 Brief JSON」获得。Brief 附加参考支持 JPG、PNG、WebP，以及 Word、Excel、含文字层 PDF 和文本文件。单份参考上限 12 MB，最多五份，其中最多两张图。长文档可从工作区资料库选定段落后加入 Brief。

投放数据采用 UTF-8 CSV。必填列为素材名称、创意方向、受众、国家、展示量、点击量、转化量、花费。可附加平台、币种列。每份文件使用同一币种和点击归因口径。数字、引号、除零、缺列、混合币种会进行相应检查。可直接使用随包提供的 **folda-demo.csv**。

## 复盘与审核口径

CTR = 点击量 / 展示量。CVR = 转化量 / 点击量。CPC = 花费 / 点击量。CPA = 花费 / 转化量。按国家、平台、受众建立可比组。页面内提供样本门槛与异常阈值。实验建议依据观察到的差异生成，可由团队在下一轮验证。

程序检查禁用词、术语、数字与单位、投放版位和证明来源。独立模型检查文化语境、措辞、事实偏离与宣称。所有正式导出均绑定当前创意版本和审阅记录。高风险条目需修正；缺少可引用证据的证明型素材会留在待处理队列。

TikTok 示例版位为预约信息流 Spark Ads Pull。平台说明见 [TikTok 版位规格](https://ads.tiktok.com/resources/help/article/tiktok-reservation-in-feed-ads-reach-frequency)。Meta 使用 Facebook Feed 视频版位的团队可读性阈值，投放前可核对 [Meta 版位指南](https://www.facebook.com/business/ads-guide/video/facebook-feed)。
